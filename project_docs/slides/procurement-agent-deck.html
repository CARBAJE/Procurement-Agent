How it works

From text to purchase order in 5 steps.

The agent orchestrates the full Beckn v2.0.0 lifecycle — discover, select, init, confirm, status — automatically and auditably.

01
Understand
Local qwen3 LLM extracts item, quantity, budget, location, deadline
< 2 sec
02
Discover
Beckn fan-out via ONIX adapter across all connected supplier networks
< 5 sec
03
Evaluate
RankNet ML scoring on price, delivery speed, risk + agent memory of past orders
< 3 sec
04
Negotiate
LangGraph engine issues counter-offers within category-specific policy caps
< 20 sec
05
Confirm
PO written to PostgreSQL, 9-event audit trail, ERP push via outbox
< 5 sec
Total wall-clock time on routine autonomous flows: ~45 seconds. Every step that previously required human intervention is now automatic — and immutably logged for SOX 404.
